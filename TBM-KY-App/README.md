# TBM-KY記録アプリ

## 1. 概要

このアプリケーションは、建設現場や電気工事などで実施されるツールボックスミーティング（TBM）および危険予知（KY）活動の内容をデジタルで記録・管理するためのiPad専用アプリです。

従来、紙媒体で行われていた記録作業をデジタル化することで、記録の作成、保存、検索、共有を効率化し、ペーパーレス化を推進することを目的としています。

## 2. 主な機能

- **記録の入力**: 画像で提供されたフォーマットに基づき、作業日、作業内容、作業者、危険予知項目などを入力できます。
- **データ永続化**: 入力した記録はiPadデバイス内に安全に保存され、アプリを再起動してもデータは失われません。
- **一覧表示**: 保存したすべての記録を日付の新しい順に一覧で表示します。
- **詳細閲覧**: 一覧から特定の記録を選択すると、その詳細な内容を読み取り専用形式で確認できます。
- **記録の編集**: （将来的な拡張機能）既存の記録を編集し、更新する機能。

## 3. 画面構成

本アプリは、主に以下の3つの画面で構成されています。

- **入力画面 (`InputView`)**:
  - 新しいTBM-KY記録を作成するためのフォーム画面です。
  - テキストフィールド、トグルスイッチ（チェックボックス）、日付ピッカーなどが配置されています。
- **一覧画面 (`RecordListView`)**:
  - アプリの起動時に表示されるメイン画面です。
  - 保存されているすべての記録がリスト形式で表示されます。
  - 右上の「+」ボタンから新規記録作成画面へ遷移します。
- **閲覧画面 (`RecordDetailView`)**:
  - 一覧画面で特定の記録をタップすると表示される詳細画面です。
  - 記録の内容がセクションごとに整理されて表示されます。

## 4. 技術的な詳細

- **言語**: Swift 5
- **UIフレームワーク**: SwiftUI
- **対応OS**: iPadOS 15.0以上（想定）
- **アーキテクチャ**: MVVM (Model-View-ViewModel)
- **データ永続化**: JSONファイルとしてデバイスのドキュメントディレクトリに保存

## 5. コード構成

プロジェクトは、責務分離を明確にするためにMVVMアーキテクチャを採用しています。

```
TBM-KY-App/
├── Model/
│   └── TBMRecord.swift      # データ構造を定義するモデル
├── View/
│   ├── InputView.swift      # 入力画面のUI
│   ├── RecordListView.swift # 記録一覧画面のUI
│   └── RecordDetailView.swift # 記録閲覧画面のUI
├── ViewModel/
│   ├── InputViewModel.swift   # InputViewのロジックと状態を管理
│   └── RecordListViewModel.swift # RecordListViewのロジックと状態を管理
└── Services/
    └── PersistenceService.swift # データの保存・読み込みを担うサービス
```

- **Model**: `TBMRecord`構造体がアプリのデータ構造を定義します。`Codable`に準拠しており、JSONへのエンコード・デコードが可能です。
- **View**: SwiftUIで構築されたUIコンポーネントです。ユーザーのアクションをViewModelに通知し、ViewModelから提供されるデータを表示する責務を持ちます。
- **ViewModel**: Viewのための状態とロジックを管理します。Viewからの入力を受け取り、Modelを更新し、その結果を`@Published`プロパティを通じてViewに公開します。
- **Services**: `PersistenceService`がデータの永続化に関するロジックをカプセル化します。これにより、データの保存方法を将来的に変更（例: CoreDataやクラウドDBへの移行）する際に、他のコンポーネントへの影響を最小限に抑えることができます。

## 6. 使用方法

1. **新規記録の作成**:
   - アプリを起動すると「TBM記録一覧」画面が表示されます。
   - 画面右上の「+」ボタンをタップすると、新規入力画面が表示されます。
   - 各項目に必要な情報を入力・チェックします。
   - 画面右上の「保存」ボタンをタップすると、記録がデバイスに保存され、一覧画面に自動的に反映されます。

2. **記録の確認**:
   - 「TBM記録一覧」画面で、確認したい記録の行をタップします。
   - 記録の詳細な内容が閲覧画面に表示されます。
